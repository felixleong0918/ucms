### 單元測試新增的兩項

- **建置設定檢查**（`tests/domain.test.mjs`）：模擬器與設定完整的正式環境可以建置；在 Vercel 上缺少環境變數、沿用示範專案 ID 或模擬器金鑰、`UCMS_MODE` 拼錯時會被擋下。

### 整合測試涵蓋範圍（`tests/integration.mjs`）

透過與網頁相同的資料層（`src/firebase.mjs`）對模擬器發出請求。被拒絕的操作都確認回傳 403。

1. **登入與帳號**：錯誤密碼、重複註冊；不能讀寫他人的使用者檔案；不能自行成為系統管理者。
2. **社團與成員管理**：只有系統管理者能建立社團；只有核心幹部能管理成員；核心幹部不能修改或移除自己；未註冊的 UID 與未定義的角色會被拒絕；社員看不到成員名單。
3. **未登入與非成員**：成員、任務、公告、會議、財務、庫存、盲注結構一律無法讀取或寫入。
4. **跨社團隔離**：社團 B 的核心幹部無法讀寫社團 A 的任何內部資料，也無法把自己加入社團 A。
5. **公告與已讀**：只能替自己標記已讀；社員無法讀取幹部公告。
6. **會議轉任務**：任務保留會議來源；負責人必須是成員、必須有截止日期；社員只查得到自己的任務、只能更新狀態；管理者看得到更新後的進度。
7. **活動報名、簽到、收費**：未登入可看公開活動、看不到草稿；不能替他人報名、不能自行標記簽到或收費、截止後與草稿不能報名、不能重複報名；幹部只能更新簽到與收費兩個欄位；參加者看得到自己的狀態；名單可匯出。
8. **財務**：結餘等於收入減支出；金額必須是正整數；一般幹部不能查閱；只有核心幹部能刪除。
9. **庫存**：新增時數量為 0；數量只能隨異動紀錄一起變更；規則拒絕負庫存、不一致的紀錄與偽造的紀錄；未啟用模組的社團不能使用。
10. **盲注結構**：幹部可儲存；社員與未啟用模組的社團不能使用。
11. **活動回饋**：已報名者每人一次；評分 1–5；表單關閉後不能提交；參加者看不到他人回覆；未啟用模組的社團不能建立表單。

### 瀏覽器流程走查（前一輪，44 項）

這一輪沒有重跑。以示範資料登入各角色，在介面上實際操作：

- 幹部：新增會議 → 決議轉任務（帶入決議、指定負責人與期限）→ 任務篩選與搜尋 → 建立公開活動 → 行事曆顯示 → 發布公告與已讀狀態 → 期限提醒。
- 參加者：公開頁進入活動 → 登入並報名（資料不完整時不送出）→ 看到簽到與收費狀態 → 提交回饋（只能一次）。
- 幹部：確認簽到與收費 → 匯出報名名單 → 建立回饋表單 → 查看回覆與平均 → 匯出回饋。
- 財務幹部：登記收入與支出後結餘正確（含小數金額）、看不到刪除、匯出財務。
- 社員：側欄只有總覽與我的任務；完成會議指派的任務；直接輸入財務或團隊管理網址會被擋下。
- 撲克社幹部：新增器材 → 入庫 → 超領被拒 → 領出 → 異動紀錄；盲注計時的開始、倒數、暫停、恢復、下一級、重設、設定級別、錯誤提示、儲存與載入結構、時間到自動切換級別。
- 核心幹部：調整成員角色、不能移除自己、社團切換器只列出自己的社團。
- 系統管理者：看到所有社團、建立新社團。
- 未加入社團的帳號：看到引導與 UID，沒有內部資料。
- 手機寬度：九個工作空間頁面、公開頁、活動頁與登入頁都沒有水平溢出；選單可開關。
- 匯出的三個 `.xlsx` 以 openpyxl 開啟，欄位與內容正確。

## 整合過程中修正的問題

- `src/main.jsx` 與 `src/styles.css` 不存在，建置失敗。
- 登入後預設停在第一個社團，即使使用者不是成員；現在只列出並進入自己所屬的社團。
- 切換使用者時會短暫顯示前一位使用者的畫面或「尚未加入社團」。
- 每次儲存都會清空頁面資料並重複讀取兩次，造成畫面閃爍與篩選狀態遺失。
- 沒有任何社團時，系統管理者無法從介面建立第一個社團。
- 公開頁從活動詳情回到列表時仍顯示舊活動；列表會列出已結束的活動。
- 按鈕元件會忽略「處理中」的停用狀態，表單內的按鈕預設會送出表單。
- 在視窗內匯出 Excel 時，下載連結未加入頁面；檔名未處理不合法字元。
- 盲注級別把休息也算進編號；重設與載入結構使用瀏覽器原生的確認視窗。
- 金額顯示為 `$`，改為 `NT$`。

## 加入 Vercel 部署時的修改

- 新增 `vercel.json`；`firebase.json` 移除 Firebase Hosting 的設定。
- 建置腳本原本只在 `UCMS_MODE=production` 時檢查設定；在 Vercel 上忘記設定環境變數時會靜靜地建置出指向本機模擬器的網站。現在在 Vercel 上一律檢查，缺少就失敗。
- 環境變數的值前後若有空白會被帶進設定，現在會先去除。
- API Key 無效時畫面原本顯示英文的原始訊息，現在顯示中文說明；未啟用登入方式與未建立資料庫也有對應訊息。
- 資料庫不存在時，讀取單一文件原本會被當成「文件不存在」，現在會回報錯誤。
- `package.json` 的 Node.js 版本範圍由 `>=22` 改為 `>=22 <27`，避免 Vercel 自動升級到未測試過的主要版本。
